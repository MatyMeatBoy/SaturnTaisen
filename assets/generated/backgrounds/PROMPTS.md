# Background generation brief

These are preliminary generated decorative extensions, not exact preservation of the original game bitmaps. References were extracted locally from the owner's KABE resources. Original references are not distributed.

The common brief used for the set: extend the matching floral motif to a widescreen decorative background; retain native flat silhouettes, palette, diagonal gradient and ordered bitmap texture; keep a calm center for the video/dialogue group; avoid text, UI, borders, invented objects, glossy shading, paper fibers and blur. Match each family rather than using cherry blossoms everywhere. Night variants use the corresponding generated day layout and native night reference palette.

Family references: KABE00/01 cherry blossoms, 10/11 trumpet lilies, 20/21 hydrangeas, 30/31 lily of the valley, 40/41 morning glory, 50/51 radial cosmos, 60/61 chrysanthemums, 70/71 plum branches, 80/81 camellias and 90/91 falling petals. Original 90 and 91 are identical; their generated files are identical too.

This is a consolidated prompt brief, not a verbatim transcript of every generation call. Per-file hashes, original reference hashes and status are in `provenance.json`. The user's preferred denser-flower first cherry-blossom proposal is KABE00. Runtime normalizes these masters onto a 416×234 grid and the matching native palette, then scales that grid only by integers. Decorative excess may be cropped.

PC references and PC-detail extensions are tracked separately. The Saturn grid and palette are not an authorization to reduce PC artwork to Saturn density.
