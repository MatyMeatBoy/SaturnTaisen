# SaturnTaisenFirst v0.1

Implementation requested directly by the owner: a launcher with a bubbly style inspired by their NewSnapRecomp, Sakura Wars 1 images, an adaptable frame, and strictly integer game scaling. Publish v0.1 to track progress and fixes, without claiming the campaign is finished.

SDL3/ImGui and the validated software backend are kept. Cream, pink, burgundy, and gold palette; capsule navigation, large rounded panels, clear states, and accessible keyboard/controller controls. The design follows NewSnap's visual principles; that project itself is not modified. Only the real title-screen capture, as specified by the owner, from local resources, with a functional placeholder presentation if unavailable.

The game image is centered using a single integer multiplier for both axes and nearest-neighbor sampling. Aspect ratio is not corrected via fractional stretching, and no incompatible high-resolution/widescreen options are offered. The frame occupies the remaining space without covering the game. On an output smaller than a native frame, the physical limit requires 1x with cropping; the normal window will have a sufficient minimum size. 4:3, 16:9, ultrawide, and 4K resolutions are verified, plus Saturn mode changes.

v0.1 includes reproducible tools, the launcher, the importer, and validation documentation. The campaign, full combat, RA, all save formats, the real automatic disc transition, and physical controller validation remain pending where no evidence exists. Do not distribute dumps, BIOS, public saves, or generated game sources. The private development package includes the compiled AOT runtime and requires the player's own discs. Local art is not added to the repository.
