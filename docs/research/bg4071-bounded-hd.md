# BG4071 bounded HD character

BG4071 is a distinct component of the disc 2 dining-room scene.
Saturn draws the character on a keyed foreground layer. The PC
donor contains the room as well. The HD compositor uses only
aligned character interiors and retains the Saturn silhouette,
table and room.

A controlled copy of the Chapter 9 0904 checkpoint advanced the
script cursor to the original BG1049/BG4071 loading block. The
121-field strict-native replay reads both original files and
shows all 1,217 native non-key character cells between fields
55 and 120. It did not inject renderer data. This verifies the
native layer and viewport for the controlled branch. Natural
branch reachability, linked HD playback and packaging remain
pending.

and writes outside none of them. Source 4 has palette fingerprint
