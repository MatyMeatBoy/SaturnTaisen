# BG4067 bounded HD character

In the disc 1 dining room, Saturn places the character on a separate
keyed layer. The PC file also contains the room. The aligned HD
registration is restricted to native-owned interior pixels with
matching donor color. It retains the native outline and the part
below row 128, including the table details.

All 1,217 non-key cells appear in the archived native frame. C++
registration accepts 527 cells and writes outside none of them.
The source-4 route requires the exact palette, tiles and visible
RGB. The PC image is decoded and prepared asynchronously. Syntax,
the offline compositor and the patch stack passed. Linked playback
and package inclusion remain pending.
