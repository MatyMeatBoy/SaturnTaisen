# v0.2.26-alpha

- Al abrir el lanzador, se revisan todos los archivos preparados, incluso si la versión sigue siendo la misma. Se recuperan discos, traducciones, tarjetas, vistas previas y recursos HD a partir de los archivos locales disponibles. Si falta una fuente, el lanzador indica cuál. Se conservan las partidas, el idioma y los ajustes.
- Se eliminó el destello lateral al confirmar «New Game» y se suavizó el paso al fondo y la imagen HD del saludo de Ogami. Ambos cambios se verificaron a 1440p.
- En Windows, el hilo principal del juego usa prioridad moderada al jugar en primer plano y recupera su prioridad anterior al perder el foco. Las pruebas locales confirmaron ese comportamiento durante una carga concurrente.
- Iris vuelve a decir «Onii-chan» en ambos discos españoles. Se unificaron «Dama demonio» y «Chico Fiesta», y se corrigió una frase de Kohran.
