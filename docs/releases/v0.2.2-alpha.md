# v0.2.2-alpha — your own files are the only input

The player supplies only **their own files**: the two Sakura Taisen Saturn discs and, optionally, the PC edition. The launcher prepares the game on their PC, in English or Spanish, and builds the HD mod. Nothing else has to be installed, downloaded or built.

## What is new

- **Preparar juego.** One field in the launcher: the folder with your files, or any one of them (the rest are looked for beside it). `preparar-juego.exe` does the work and reports progress.
- **Any container, recognized by content.** A Saturn disc is identified by the SHA-256 of its data track: `.cue` with one or two track files, a single `.bin`/`.img`, a plain `.iso`, a `.zip`, or a folder with any of them. The PC edition can be a disc image (`.mdf`/`.iso`, plain or raw sectors, read in place), a folder with its cabinets, or the installed game folder.
- **Discs already patched with the English translation v2.1 are accepted as they are** and used directly as the English base.
- **Language layers** in `parches/` (differences only): *Inglés v0.1 Taisen* (original → English base, 4.0 + 4.1 MB), *Español v0.1 Taisen* (English base → Spanish, 0.58 + 0.58 MB) and *subtitled videos* (101 + 123 MB). The English base is the English translation v2.1 repackaged for this port: identical except that the video container `/SAKURA4` keeps the original bytes, which shrinks the base from 246 + 280 MB to about 8 MB; with the video layer the prepared disc is byte for byte the v2.1 one. Credits of that team: `parches/CREDITOS.md`.
- **Nothing is rebuilt needlessly.** Prepared discs carry a receipt; a disc that still matches is kept, the Spanish disc alone is rebuilt from the prepared English one when only the Spanish layer changed, and the HD pack is kept while it matches the release's recipe. Extracting a newer release over the folder keeps `game/`, `hd-resources/` and `user/`.
- **HD mod built from the player's PC edition**: 19 decorative backgrounds and 302 of 304 portraits, everything the runtime currently consumes. No original PC file is kept. `tools/build_hd_recipe.py` and a test keep the release recipe equal to the approved matches, so approved HD work always reaches the next release.
- **Launcher.** Home page fits 980×600: title, Play, four switches (language, presentation, HD text, HD mode — one switch for backgrounds and portraits) and the setup card. Rounder cards and buttons with a shine, a bubble-and-grain backdrop, dropdown words that always fit. The language switch takes effect at once.
- **Frontends (RecompLauncher / Easy Setup).** Single entry point `SaturnTaisen.exe` with `--rom`, `--language`, `--no-launcher`, `--setup`, `--fullscreen`, `--widescreen`, `--integration-info`, `--help`; `recomp-launcher.json` describes it. `SaturnTaisen.exe --rom "<file or folder>" --language es --no-launcher` is the whole setup.
- **Fixed:** accented words in the options page were shown broken ("AutomÃ…tico"); the launcher now repairs them.

## Verified

All runs below used the package's own executables with `PATH` limited to Windows System32 (no Python, MSYS or toolchain) unless noted.

| Input | Result |
| --- | --- |
| Original discs (`.cue` + two `.bin`) and `SAKURA.mdf` in a folder, via `SaturnTaisen.exe --rom <folder> --language es` | `game/disc1`, `disc2`, `disc1-es`, `disc2-es` and the HD pack built; profile points at the Spanish disc |
| Same files via `preparar-juego.exe prepare --folder` (source tree) | same |
| Discs already patched with English v2.1 + the PC edition as an extracted folder (source tree) | same, in 34 s |
| Second run over a prepared install, asking for English | nothing rebuilt, 2.9 s, language switched |

- In every case the four prepared data tracks are **byte-identical** (SHA-256) to the owner's reference discs built with the earlier pipeline (English v2.1 and the Spanish build of v0.2.1-alpha), and the audio tracks are identical.
- HD pack: the release runtime prepared 19/19 backgrounds; 302 portraits whose pixels match the reviewed hashes.
- Cold boot of the prepared Spanish disc on the release runtime (strict AOT, software video, 7,001 frames): title in Spanish ("Pulsa Start"), exit code 0. The English base without the video layer also boots and plays the opening video.
- Launcher: `--help` and `--integration-info` print through the entry point; pages captured at 980×600 with `--screenshot` (home, options, controllers) and inspected.
- Tests: `tests/test_taisen_setup.py` (19 tests: every disc container, zip and folder discovery, PC edition forms, language profile, receipts, patch manifest, portrait recipe coverage, frontend manifest), the launcher disc fixture, the research index.

## Not verified / limits

- The launcher was checked by screenshots and by running its helper and flags; **nobody clicked through the new section by hand** in this block.
- `.iso` or single-file inputs without an audio track produce a silent audio track (the data track is still verified). Synthetic tests cover those containers; the real-disc runs used `.cue` + `.bin` and prepared `.iso` + `.wav`.
- `.7z`/`.rar`/`.chd` are not read: extract them first. Only the supported edition is accepted (GS-9037 V1.005, original or English v2.1); other dumps are rejected with a message instead of being patched.
- Runtime unchanged: the tested 674,182-block executable of test.4 (SHA-256 `df68e9db…`, patch0050). No new campaign coverage is claimed; chapter 1 end to end and the full campaign are still not certified. Its in-game settings menu still shows the broken accents (needs a runtime build, T83).
- Spanish: episode cards, the LOADING screen, the extra menu (`OMALL.DAT`) and video subtitles remain English. Chapters 3–6, 9 and 10 were checked on the built disc image only, not played.
- HD: scene images (12 pairs confirmed as data), PC videos, tactical, HUD and full-body art are not connected to the runtime yet.
- A physical RX 6900 XT / M30 run is still the owner's test.

## Size

Program and tools are about 320 MB compressed, plus 9.3 MB of language layers and 224 MB for the subtitled videos. The video layer is lossless (it reproduces the v2.1 container exactly; LZMA and cross-disc reuse were measured and gain under 5 MB), so it cannot shrink further without changing the picture. It is optional: remove the two `videos-en-*` files from `parches/` before preparing and the game uses the original videos.
