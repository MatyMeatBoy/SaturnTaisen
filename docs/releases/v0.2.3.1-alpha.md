# v0.2.3.1-alpha — smooth at any window size, Zoom box steady, one program in data/ + roms/

A fix release on top of v0.2.3-alpha, from the owner's play test at 2560x1440.

## What is new

- **No slowdowns from the window size.** The enhanced presentation blended the panels, picture shadow and fades over the HD backdrop once per *window* pixel, so the title screen, dialogue and transitions slowed down on large screens (1440p: composite 6.4 ms, peaks 24 ms per frame). It now decides per native pixel, reuses window rows that share a native row and a backdrop row, mixes once per backdrop pixel run and splits rows among spare cores. Same pixels: `tests/test_window_composite_equivalence.cpp` (144 cases identical, up to 4K) and, against the released runtime, identical per-frame state hashes and window pictures at 2560x1440. Random play at 1440p: composite 5.0 → 2.0 ms average.
- **The Zoom dialogue box no longer jumps** between scenes: while only the box is left on the floral plane (a load), it keeps its Zoom place.
- **Layout `SaturnTaisen.exe` + `data/` + `roms/`.** The launcher is the program at the top (static, a window program: no console ever opens) and shows a loading screen at once; the game, helpers, prepared discs, HD pack and saves are in `data/`; the player's files go in `roms/` (`discos/` still found).
- **Runtime:** cursor auto-hide (patch0052), repaired accents in the in-game options and Zoom as default (patch0055), frame profiler (`SATRECOMP_FRAME_PROFILE`, `SATRECOMP_FRAME_PROFILE_SLOW=ms`).
- **Helper:** the presentation chooser's previews are made from the player's own title screen (muted); `prepare` with no argument reads `roms/`; the profile follows the install's HD pack.
- **Size (T91):** the runtime is again about 855 MB. A rebuild had compiled two generations of `gen/blocks_*.cpp` (1,357,536 blocks for 674,182); `build_runtime.py recompile` now clears `gen/` first.

## Not verified / limits

- Emulation itself is about 9 ms per frame (SH-2 ~4, VDP drawing ~4, sound ~1): the next performance target (T86).
- Japanese was booted through the intro only. Campaign limits as in v0.2.2.
