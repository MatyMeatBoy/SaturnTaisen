# v0.2.8-alpha

This Windows release prioritizes smoother dialogue in Enhanced mode. The shared renderer reuses unchanged floral composites and performs less work when a new animated mouth or eye pose appears.

In the 1440p Chapter 1 park replay, average background and composition time fell from 3.63 to 1.83 ms, with identical guest hashes and sampled video. The other-PC flicker and live audio remain to be confirmed. See the [performance evidence](../research/park-speech-performance.md).

This release also brings the integrated episode and scene improvements, portrait and body fixes, HD inventory controls, and tactical ground updates since v0.2.7. Original remains available in the launcher. MAP05 has a render witness on the interpreter path and incomplete strict AOT coverage. The public package uses the player's own discs and optional PC edition.
