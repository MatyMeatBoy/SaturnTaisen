# v0.2.3-alpha — one program, a simpler launcher and the complete HD pack

The player still supplies only **their own files** (the two Sakura Taisen Saturn discs and, optionally, the PC edition). This release changes how the package looks and how little the player has to do.

## What is new

- **One program.** The extracted folder shows `SaturnTaisen.exe`, `discos/`, `LEEME.txt` and `recomp-launcher.json`; everything else (launcher, game, helpers, DLLs, licences, sources, prepared discs, saves) is in `app/`. No `.bat` files. The root `SaturnTaisen.exe` is a 19 KB static starter (window subsystem: a double click opens no console) that runs `app/SaturnTaisen.exe` with the same arguments and output, so `--help`, `--integration-info` and Easy Setup work as before.
- **Automatic setup.** Copy the discs (and the PC image) into `discos/` and open `SaturnTaisen.exe`: the files are recognized and the game is prepared on its own, with a thick animated progress bar.
- **Simpler launcher.** *Inicio*: title, Jugar and three switches — IDIOMA (flags: Español, English, Japonés), TEXTO HD and MODO HD. *Opciones* starts with one *Tus archivos* card (one *Elegir…* for any disc or PC image, the rest is found beside it; Preparar/Revisar; Abrir for saves and logs) and a one-button save import. Removed: the presentation switch and cards on the home page, the generic disc card, the folder card and «Iniciar en silencio». The game is started at above-normal priority; on Windows 11 the title bar uses the launcher's colours.
- **Japanese.** When the original discs are given, they are also kept untouched as the Japanese option (`app/game/discN-ja`).
- **Complete HD pack (T89).** The PC edition is read once and everything the HD mod will need is kept in `app/hd-resources/pc/` with a SHA-256 manifest: every image (backgrounds, scenes, events, CG, maps, units, large characters, endings, eye catches, titles, menus, items, walls), the 52 videos and their tables — about 2,375 files and 1 GB, only on the player's PC. Audio is not taken. Today the runtime uses 19 backgrounds and 302 portraits from it; categories integrated later need no new preparation. A prepared HD pack is switched on.
- **Zoom by default** for scene view on a new profile; missing first-run settings are filled in without overwriting choices.

## Verified

- Owner's v0.2.2 folder rearranged to this layout with the new launcher and helper: automatic preparation reached 100 % (English, Spanish, HD), Japanese discs prepared, complete HD pack built (2,375 files, 1,037,640,097 bytes, 52 videos); `--integration-info` through a pipe; launcher pages captured and inspected.
- `disc1-ja` boots on the release runtime: 1,500 frames, 100 % recompiled, 0 interpreted (intro only).
- Tests: `tests/test_taisen_setup.py` (22), `tests/test_package_art.py` (5).
- Package built by `tools/package_release.py`, extracted and checked as described in the validation receipt.

## Runtime

Unchanged: the tested 674,182-block executable of test.4 (SHA-256 `df68e9db…`, patch0050), 855 MB. Prepared but **not** in this release (they need a qualified runtime build): patch0052 cursor auto-hide, patch0055 (repaired accents in the in-game options, Zoom as the runtime default) and patch0056 (frame profiler and a faster enhanced composite).

## Performance findings (for the next runtime, T86)

Measured on the title screen with the frame profiler (patch0056): emulation about 8.5–9 ms per frame (SH-2 4.0, VDP drawing 3.3, sound 1.1) and the enhanced presentation 2.8 ms, of which 2.5 ms was the backdrop composite done once per **window** pixel. patch0056 does that composite once per native pixel and copies blocks, with identical pictures. Startup HD preload during the title and the software VDP renderer are the next targets. A runtime rebuilt on this PC came out twice the size of the released one (1.7 GB), so it is not shipped until that is understood.
