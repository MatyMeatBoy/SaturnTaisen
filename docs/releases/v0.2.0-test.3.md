## Packages

The public release contains the program, DLL, source code and patches, and permitted generative art. It does not contain discs, BIOS, scripts, saves, or original PC assets.

The authorized personal ZIP is local and separate from GitHub: program, disc 1 English v2.1, and already-processed HD. Includes the Saturn videos from the disc; PC videos are not yet integrated. Does not include the full PC installation. It is extracted into a new folder and Jugar.bat is opened; it does not require installing Python, MSYS2, SDK, or an external BIOS. The final unified product will require both discs. Preserve user/ and its saves when updating.

The hashes and tests of the extracted package are recorded when the delivery is closed. The existence of this document does not certify that the ZIP is already published or tested on the target machine.
