# v0.2.7-alpha — more HD scenes and insets, the presentation is asked once, borderless by default

A base release: everything integrated since v0.2.6-alpha (SDK patches 0108 to 0121), built locally on 2026-11-19. Layout `SaturnTaisen.exe` + `data/` + `roms/`, as before. The package never contains discs, BIOS or saves; the launcher prepares everything from your own files.

## What is new

- **The presentation is asked once (patch 0121).** The launcher shows no preselected mode between 4:3 (Original) and 16:9 (Enhanced). If nothing is chosen, the game asks on the first launch; once chosen, in the game or in the launcher, it is saved (`presentation_chosen=1`) and never asked again unless you change it. Existing profiles without that key are asked once.
- **Borderless by default (patch 0121).** The game opens in a borderless window over the display with integer scaling; F11, `--fullscreen`, `--windowed` and the launcher's fullscreen setting keep working.
- **More HD scene pictures.** 62 rows of shared-palette pictures are resolved (patch 0118; identical PC images keep the lowest name, tint variants are chosen by comparison with the Saturn picture), the BG2248 vertical panorama (0119) and the BBG204 tactical illustration (0120) draw in HD, and the scene table is generated from the register. HD progress is now 57.3 % (1025/1787 candidates, see `docs/HD_PROGRESS.md`); the count comes from the coverage register.
- **EVE insets and menus.** EVE0116 (0108), EVE0118 (0109) and EVE002 (0110) insets, the CD-1 load emblem (0112), the PC ground of tactical `Stage21` (0113) and the native underlay around `NC3250` (0116).
- **Lettering.** Generated `CARGANDO` lettering in Spanish Enhanced mode; the four square battle item cards decode.
- **Tools and shards.** The shards are split by picture family (TP1-TP9), with a speed rule (connect, compile, keep the replay hashes; no per-picture verification) and a one-in-ten spot check of the connected pictures.
