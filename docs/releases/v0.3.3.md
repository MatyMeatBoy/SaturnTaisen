# SaturnTaisen v0.3.3

- El lanzador de Windows lleva el icono de SaturnTaisen y muestra el nombre del proyecto.
- Inicio ofrece instalar el mod HD cuando encuentra la edición de PC. Desde la misma opción se puede indicar dónde está.
- Se corrigió el rótulo español «Pulsa Start» de ambos discos.
- En modo Mejorado, las películas con una mezcla floral reconocida se funden sobre el fondo ancho vigente. La sombra acompaña el fundido y Zoom conserva el encuadre de la caja al pasar por una película de historia. Se corrigió el salto de un cuadro reproducido al aparecer Sakura en el parque.

Las comprobaciones de esta versión cubren rutas seleccionadas de vídeo, diálogo y mapas. El tiempo por cuadro puede variar con el equipo y la carga.
