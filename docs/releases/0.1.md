# SaturnTaisenFirst v0.1.0 · Development

First logged delivery for Windows x64. It is a preliminary version: it does not yet certify the whole campaign or all controllers.

## Included

- Strict AOT runtime with 580,328 SH-2 block variants. Normal execution stops when it hits untranslated code; it does not fall back to the SH-2 interpreter.
- Native launcher with rounded panels, a cream/pink/burgundy/gold palette, and cherry blossoms, inspired by the owner's NewSnapRecomp.
- A single image: the title screen. It is prepared from the player's local disc in their profile; no extracted images are distributed.
- Centered game with uniform integer and nearest scaling, with no fallback to fractional scale. Frame adapts to remaining space. The native grid, e.g. 320×224, is preserved without stretching it to force another aspect ratio.
- Save import for BUP, SAROO, interleaved/compact memory from emulators, and individual explicit SSF. Creates a managed copy, allows activating it, and returning to the regular save.
- Portable distribution with the required DLLs, licenses, integration sources, tools, and reproducible patches. Requires the player's own discs; for English, their images patched with v2.1.

## Verified fixes

- CD search by track/FAD and pauses: removes the incorrect path that ended up at the BIOS exit service.
- Sector invalidation when replacing a media reader.
- Native code retention: respects disabled cache, cache-through access, CCR.CP, line purge, and reset. Tested on both RAMs and with 8/16/32-bit writes.
- Launcher close with an active child process: removes a reproduced freed-memory access by protecting the page of the destroyed object. Close-time warnings are synchronized before SDL shuts down.
- Save reading: an invalid or truncated existing file is rejected without reformatting or modifying it.
- Disc recognition with SDL paths ending in a separator, visible disc number, and rejection of unvalidated revisions.
- Individual SSF format: preserves the language byte 11, separate from the packed date.

## Evidence

- 46 local font/hardware/frontend tests pass. Real game tests require the owner's own files and do not run without them.
- 119,781 continuous frames of exploration, saving, and loading episode 1, documented in the previous validation.
- 3,001 repeated frames entering battle and 9,001 to its first playable field match the same runtime's interpreter. These do not equal completing the battle or an independent Saturn hardware certification.
- Two public saves kept locally load episode 8 and Finale on disc 2 for 9,501 AOT frames. Importing, activating the copy from the UI, and loading episode 8 from the launcher were also verified.
- Window captures at 960×720, 1366×768, 2560×1080, and 3840×2160: each native pixel occupies a uniform 3×3, 4×4, or 9×9 block. The geometry also tests several interlaced modes.
- The portable candidate boots with PATH limited to Windows System32 and generates its title from the local disc, without depending on the development MSYS2.

Details and limits of the comparisons: [runtime-validation.json](../research/runtime-validation.json). Instrumental differences in serialized states are identified per field; no arbitrary machine differences are hidden.
