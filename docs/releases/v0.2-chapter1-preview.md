# v0.2-dev — chapter 1 test build

Local checkpoint for playing and debugging, not the final v0.2 release nor a certification of a complete chapter/campaign. v0.1.5 remains unchanged.

Includes optional HD font with uniform proportions and dialogue clipping; Original or Enhanced presentation; Original or Zoom scene display; preliminary generated Saturn/PC backgrounds; optional HD preload from the launcher; local pack of 191 portrait proposals with original fallback; Bluetooth/2.4G M30 detection and manual profile for generic XInput identity; SDL controller remapping; save import. Maximum 16:9 and integer scale. PC bodies will be aligned with uniform height-based scale and the head/torso center axis; incomplete bodies with no eyes/mouth are not yet integrated.

Local shortcuts: `Probar SaturnTaisenFirst capitulo 1.bat` (launcher/start), `Probar escena HD capitulo 1.bat` (Iris scene with a local state), and `Abrir logs SaturnTaisenFirst capitulo 1.bat`. Own profile local/profiles/chapter1-preview: it does not modify the v0.1.5 save or the emulator sources. The initial configuration enables Enhanced, Zoom, and preload; it can be changed in launcher/settings. The launcher closes once the game is confirmed ready. Logs in the profile, especially logs/game.log. F11 fullscreen; Esc/F1 or Select/Back/Start+Select opens settings; M30 Heart/Guide also works if the device exposes it.

Explicit pending items: complete HD bodies/expressions; integration of PixelGen v1 in map/camera coordinates; 16:9 tactical field and relative HUD; real switch between discs and complete campaign; RetroAchievements; physical validation of all controller modes/firmwares. The PixelGen v1 right extension is artistically approved, but it is not yet an integrated moving extension. The tactical GPU prototype is disabled in this build. PC execution/translation remains on hold.

The ZIP package contains executables, dependencies, own fonts/patches, and generated backgrounds approved by the manifest. It does not include discs, BIOS, states, saves, or original PC sprites. The local shortcuts use the owner's assets already present on this machine.

Verification before packaging: 82 tests passed in 148.379s; native build and launcher correct. M30 profiles were tested with fixtures and a virtual controller; physical validation pending.
